# Замер скрытого провайдерского ввода у Grok

15 октября 2026. Скрипт `probe.py`, сырые ответы `results.json`. 9 запросов, $0.0134. Маршрут как в action-пилотах: один провайдер, без fallback. Модель ни о чём не спрашивали: только «hi», нейтральный абзац и «hi» с системным промптом parcel-office v14.

| модель | «hi» | абзац 582 симв. | «hi» + наш system (800 симв.) | закешировано |
|---|---:|---:|---:|---:|
| Grok 4.7 (xAI) | **1243** | 1364 (+121) | 1404 (+161) | **1152** уже на первом запросе |
| Qwen 3.8 Max (Alibaba) | 50 | 169 (+119) | 200 (+150) | 0 |
| Gemini 3.8 Flash (Google) | 2 | 121 (+119) | 162 (+160) | 0 |

Прирост от нашего текста у всех трёх моделей почти одинаковый: +119–121 на абзац, +150–161 на системный промпт. Значит, токенизатор у Grok обычный. Но на пустом «hi» Grok тарифицирует 1243 токена против 2 и 50 у контрольных моделей. Это постоянная добавка примерно в **1200 токенов**, которую ставят до нашего текста. Из неё 1152 токена закешированы с первого же запроса, то есть префикс один и тот же для всех запросов, включая обе наши среды.

**Вывод:** xAI добавляет к каждому запросу Grok скрытый текст примерно на 1200 токенов. Наш системный промпт не заменяет его, а добавляется после. Содержание из трасс известно только косвенно: «safety rules», «PRIORITY», «DISALLOW list» с категориями cyber, bio, chem/nuclear, drugs, copyright, jailbreak. Мы его не запрашивали и утверждать его текст не можем.

**Что это значит для эксперимента:** любая наша среда работает у Grok поверх этого текста. Правками среды его не убрать.

## Прямой API xAI (15.10, `probe_direct.py`, `results-direct.json`)

Те же три запроса к `grok-4.7` на api.x.ai, ключ Гоши из Связки ключей, ~$0.005.

| вход | OpenRouter → xAI | api.x.ai напрямую |
|---|---:|---:|
| «hi» | 1243 (1152 из кеша) | **1243** (1152 из кеша) |
| абзац | 1364 | **1364** |
| «hi» + наш system | 1404 | **1404** |

Числа совпадают до токена. **Префикс добавляет сам xAI на своём API, не OpenRouter.** Чистого маршрута к Grok 4.7 нет. Значит, это свойство продукта: любой агент на Grok 4.7 через API работает с этими инструкциями. Распознавание теста, которое они вызывают, — поведение модели в реальном развёртывании, а не артефакт нашего канала.
